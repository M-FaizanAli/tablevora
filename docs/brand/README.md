# Tablevora identity

Tagline: **A calmer service. A smarter restaurant.**

- Forest: `#123E32` — hero surfaces and logo background.
- Green: `#17634B` — primary actions and links.
- Cream: `#F7F5EF` — page background.
- Mint: `#A9E8C8` — accents on dark surfaces.
- Ink: `#182D26` — text.
- Typography: Outfit for headings, Geist for interface text, Geist Mono for code/numbers where needed. Fonts are self-hosted by Next.js.

The table/T mark was generated using the built-in image generation tool on 2026-10-26. Prompt: “Create a production-ready square app icon for Tablevora, a premium restaurant operations software brand. A bold simple geometric cream T monogram which also suggests a dining table, with a small mint leaf-like rounded accent at upper right. Flat forest green (#123E32) rounded-square tile filling the image, generous safe margins 22 percent around the central cream (#F7F4EA) mark, mint accent (#A9E8C8). Crisp minimalist vector-like edges, balanced geometry, readable at 32 pixels. No text, no mockup, no shadows, no gradients, no texture, no border. Single icon only, square composition.”

The application now uses `apps/web/public/brand-mark.svg` as its crisp, full-bleed master mark. It avoids the white canvas margin in the earlier raster logo. App icons and favicon are rendered from the same vector design. `brand-lockup.png` remains the README wordmark.

The six-item sample menu contact sheet at `apps/web/public/images/demo-menu.webp` was generated with this prompt: “A clean 3-column by 2-row contact sheet of six distinct, photorealistic restaurant menu item photos, each tile edge-to-edge with no gutters, borders, labels, or text. Top row: a tall glass of virgin mojito with mint and lime, a glass of cola with ice, a classic margherita pizza with basil. Bottom row: Indian butter chicken curry with naan, paneer tikka with grilled vegetables and onion, spicy chicken 65 with curry leaves. Consistent soft natural restaurant lighting, warm neutral tabletop, overhead to three-quarter food photography, appetizing and realistic.” The demo crops each tile as a fallback for its six seeded sample items; restaurant-provided menu images take precedence.

The working name was screened for obvious exact-name restaurant-software conflicts by web search, not a formal trademark clearance. No domain has been purchased.
