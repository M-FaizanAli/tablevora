# Tablevora identity

Tagline: **A calmer service. A smarter restaurant.**

- Forest: `#123E32` — hero surfaces and logo background.
- Green: `#17634B` — primary actions and links.
- Cream: `#F7F5EF` — page background.
- Mint: `#A9E8C8` — accents on dark surfaces.
- Ink: `#182D26` — text.
- Typography: Outfit for headings, Geist for interface text, Geist Mono for code/numbers where needed. Fonts are self-hosted by Next.js.

The table/T mark with a mint leaf accent was generated using the built-in image generation tool on 2026-10-26. Prompt: “Create a production-ready square app icon for Tablevora, a premium restaurant operations software brand. A bold simple geometric cream T monogram which also suggests a dining table, with a small mint leaf-like rounded accent at upper right. Flat forest green (#123E32) rounded-square tile filling the image, generous safe margins 22 percent around the central cream (#F7F4EA) mark, mint accent (#A9E8C8). Crisp minimalist vector-like edges, balanced geometry, readable at 32 pixels. No text, no mockup, no shadows, no gradients, no texture, no border. Single icon only, square composition.”

Assets: `apps/web/public/logo.png`, `brand-lockup.png`, `icons/*`, and `apps/web/app/favicon.ico`.

The working name was screened for obvious exact-name restaurant-software conflicts by web search, not a formal trademark clearance. No domain has been purchased.
